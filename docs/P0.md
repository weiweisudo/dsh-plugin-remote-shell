# P0 计划：远程机器执行通道

## 1. 目标

1. 目标机 agent **主动出站**连接 DSH，不需要 sshd / WinRM / 入站端口
2. DSH 插件维护机器台账，提供 `remote_hosts` / `remote_exec`
3. Linux 端到端跑通；Windows 交叉编译并完成局域网冒烟
4. 协议为 P1 PTY、P2 文件传输预留消息类型

## 2. 非目标

- 不做交互终端（P1）
- 不做文件传输（P2）
- 不做配对码 / 多用户 / 自动 token 轮换（P0 手工 token）
- 不做 Windows 服务安装（用户态启动优先）
- 不接管系统 `web_search`
- 不依赖 Cloudflare Worker / MCP server

## 3. 交付物

| 交付物 | 说明 |
|---|---|
| `agent/` | Go 单文件，Linux/Windows amd64 |
| `plugin/` | DSH bundle（host + client） |
| `docs/protocol.md` | P0 消息子集 |
| `docs/acceptance.md` | 验收记录 |
| 构建脚本 | `make build` 或等价 |

## 4. 架构

```
目标机 agent ──WSS──> DSH webServer /api/remote-shell/agent
                         │
                         ├─ 机器台账 machines.json (600)
                         ├─ 工具 remote_hosts / remote_exec
                         └─ 侧边栏卡片：状态、最后在线、执行测试
```

- agent 只监听 `127.0.0.1`（保留上游约束），主动连 DSH 时使用出站 WS
- DSH 通过现有 `https://dsh6.potatooo.top:777` 反向代理暴露 WS 端点
- P0 不做 agent 间互通；一台 agent 一条连接

## 5. 协议（P0 子集）

帧格式：JSON 文本帧；后续 PTY/文件使用二进制帧。

```
agent -> plugin:
  hello        {machine_id, version, os, arch, token}
  heartbeat    {ts}
  exec_result  {id, exit_code, stdout, stderr, truncated, duration_ms}

plugin -> agent:
  hello_ok     {server_time}
  exec         {id, command, timeout_seconds}
  ping         {ts}
```

约束：

- `command` 在 Windows 用 `cmd /c`，Linux/macOS 用 `sh -c`（沿用上游）
- 请求体 ≤ 64 KiB；stdout/stderr 各 ≤ 1 MiB
- 默认超时 30s，上限 3600s
- 无 PTY、无持久 shell 状态（P0）

## 6. 机器台账

```json
{
  "machines": [
    {
      "id": "m_xxx",
      "name": "Windows PC",
      "os": "windows",
      "arch": "amd64",
      "token_hash": "sha256:...",
      "allowed_roots": ["C:\\Users\\me\\Downloads"],
      "created_at": "2026-10-26T12:00:00Z",
      "last_seen": "2026-10-26T12:00:00Z",
      "status": "online"
    }
  ]
}
```

- 文件权限 600
- token 只存哈希；agent 侧保存明文 token 文件
- P0 通过插件设置页或 CLI 添加机器，手工分发 token

## 8. 验收标准

- [ ] Linux agent 通过 `wss://dsh6.potatooo.top:777/api/remote-shell/agent` 连上
- [ ] `remote_hosts` 显示机器在线
- [ ] `remote_exec` 执行 `uname -a`，返回 exit 0 与 stdout
- [ ] 断开 agent 后 30s 内标记离线；重启后自动重连
- [ ] 错误 token 被拒绝，且不注册机器
- [ ] 目标机无任何入站监听端口
- [ ] Windows exe 能在普通用户下启动并执行 `hostname`

## 9. 风险

| 风险 | 处理 |
|---|---|
| Lucky / DSH 对 WebSocket upgrade 的支持 | 先用 `dsh-server-deck` 的 PTY 路由验证；失败则 P0 退回静态隧道 |
| DSH 插件 API 版本差异 | 以当前 `0.2.1-rc.2` 的 `registerUpgrade` 为准 |
| Windows Defender 拦未签名 exe | 自用接受；分发前签名 |
| token 泄露 | P0 手工最小化；P1 加配对码与轮换 |
| 服务模式权限过高 | P0 用户态运行；不做 SYSTEM 服务 |

## 10. 里程碑

- D3-D4：T3-T5，插件可列出并执行
